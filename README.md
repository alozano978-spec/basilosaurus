# 🦴 Basilosaurus — Apex Terminal Intelligence

**Open-source terminal AI platform.** Based on [CodeWhale TUI](https://github.com/Hmbown/CodeWhale) by Hmbown. MIT licensed.

## What It Is

Basilosaurus is a terminal-native AI coding agent. It runs in your terminal and works with any LLM provider — DeepSeek, Anthropic, OpenAI, xAI, Ollama, and 30+ more. It has vision, hands (desktop control), and a brain (multi-agent swarms).

Named after the prehistoric apex whale that ruled the Eocene — 60 feet, zero predators, absolutely dominant.

## Features

- **Multi-Agent Swarm** — deploy 6+ agents in parallel
- **36+ Providers** — any LLM, any endpoint
- **Terminal-Native** — runs where you work
- **100% Local** — your API keys, your machine
- **9 Languages** — i18n interface
- **MIT Licensed** — free for anything

## Install

### Download pre-built binary
See [Releases](https://github.com/alozano978-spec/basilosaurus/releases) for Windows, macOS, and Linux binaries.

### Build from source
```bash
git clone https://github.com/Hmbown/CodeWhale.git
cd CodeWhale
cargo build --release
```
